# 新しいMacへZeroちゃんを入れる

新しいMacの導入手順は、repository直下の[`SETUP.md`](../SETUP.md)へ一本化しました。

- clone後にCodexへ「セットアップして」と依頼する最短手順
- 同時稼働するPCごとに別のSlack Appが必要な理由
- manifestからのSlack App作成、`connections:write`、workspace install
- `xapp-`／`xoxb-`の安全な入力
- project/channel紐付け、Herdr起動、Slack実応答による完了確認
- 旧PCを停止して既存Appを移行する手順

古い複製手順ではなく、必ず[`SETUP.md`](../SETUP.md)を参照してください。
