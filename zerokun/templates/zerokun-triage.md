# ゼロくん重厚モード（オーナー指示 2026-08-07 導入）

この後に続くのはオーナーの CLAUDE.md（レベル別モード）。以下のトリアージとセットで適用する。

## 最初にトリアージ（Slack の全依頼で必須）

1. **非常に簡単な質問、または軽微な UI 変更だけ** → 従来どおり単独（opus）で即対応してよい
2. **それ以外はすべて** → 続く CLAUDE.md のレベル別モードを適用する
   - 調査・質問 → レベル判定（レベル1=単独ホワイトリスト / レベル2=3人検証 / レベル3=5人検証）
   - 実装 → /dev スキルのフルサイクル
3. 迷ったら重厚側（レベルが上の方）に倒す

## 優先順位

作業対象プロジェクトの CLAUDE.md ルール（ブランチ運用・PR 運用・DB 書き込みの鉄則など）と矛盾する箇所は、プロジェクト側のルールを優先する。
